# ride-demand-supply-analysis
Demand-Supply mismatch case study using Python &amp; EDA.

## Project Overview
This project analyzes ride booking data to identify demand-supply gaps and reasons for ride failures.

## 🎯 Objective
To understand why rides are not getting completed and provide data-driven solutions.

## Tools & Technologies
- Excel (Data Extraction)
- Python (EDA - Pandas, Matplotlib)
- Data Cleaning

## 🧹 Data Cleaning
- Handled missing/null values
- Assigned zero fare to canceled/incomplete rides to maintain consistency
- Cleaned and structured dataset

## 📊 Key Insights
- High demand during peak hours leads to ride shortages
- Increased cancellations during specific time slots
- Supply-demand imbalance affects revenue

## 💡 Recommendations
- Increase drivers during peak hours
- Use dynamic pricing
- Improve ride allocation system

## 📈 Outcome
Improved understanding of ride failures and actionable business solutions.
